# GoldGuard AI · 黄金企业风险雷达 — Web 产品（离线演示）

这是本次笔试的**可运行 Web 产品**。只用 Python 标准库实现，**无需安装依赖、无需 API Key、无需联网**。

## 启动

```bash
cd web
python run.py          # 然后浏览器打开 http://127.0.0.1:8765
```

或双击上一级目录的 `启动演示.bat`（Windows）。

可选参数：

```bash
python run.py --host 0.0.0.0 --port 8000   # 供局域网/容器访问
```

## 目录

```
web/
├── run.py              # 零依赖 HTTP 服务 + 看板 API + 运行模拟
├── ui/
│   ├── index.html      # 风险驾驶舱（沿用真实看板界面，已脱敏并扩展）
│   ├── app.js          # 前端逻辑 + “AI 证据链”标签 + 人工复核按钮
│   └── about.html      # 产品说明 / AI 方法 / 非目标 / 成功标准
├── data/fixtures.json  # 构造/脱敏数据（8 家示例企业 + 4 类来源）
└── tests/smoke_test.py # 主链路/数据缺失/降级/合规边界 冒烟测试
```

## 体验路径（主链路）

1. 打开首页 → 风险驾驶舱（指标、企业清单、实时日志）；
2. 点「开始排查」→ 12 个阶段按真实顺序推进，日志实时滚动；
3. 点任一企业 → 弹窗 → 切到「**AI 证据链**」标签：
   - 事实证据（来源 / 观察时点 / 原始入口 / verified-partial-unavailable）；
   - 推断（标注依据与把握度）；
   - 不确定项、改变结论的条件；
   - 「采纳 / 修改 / 标记误报 / 转人工」人工复核按钮。
4. 重点看两个反例：
   - **示例企业G**：备案与官网数据缺失 → 结论=「待核实」，证据节点 `unavailable`；
   - **示例企业H**：LLM 不可用 → 降级本地规则并标注“把握度低、需人工复核”。
