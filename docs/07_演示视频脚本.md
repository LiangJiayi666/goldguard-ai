# 07 · 演示视频脚本（90 秒，可选交付）

> 目标：直接演示产品，不用 PPT 代替体验。录屏分辨率 1920×1080，提前打开 `http://127.0.0.1:8765`。

## 分镜

| 时间 | 画面 | 口播 |
|---|---|---|
| 0–10s | 首页风险驾驶舱全景 | “GoldGuard AI，面向黄金产业链的风险雷达。它把备案、官网、社媒、公告这些碎片信息，变成可追溯、可复核的风险卡片。” |
| 10–25s | 点「开始排查」，12 阶段推进、日志滚动 | “一次排查走完十二个阶段：备案查询、官网抓取、OCR、关键词、社媒账号发现与核验、内容抓取、风险研判、证据整理。” |
| 25–45s | 点「示例企业A」→「AI 证据链」 | “每条风险结论都能回到来源。这里是事实证据：来源、观察时点、原文摘录、以及 verified / partial / unavailable 状态。” |
| 45–60s | 滚动到推断与不确定项 | “事实和推断严格分开。推断标注了依据和把握度，还有不确定项，以及——**什么信息变化会改变这个结论**。” |
| 60–72s | 点「修改」，输入意见 | “AI 只给建议，最终由人确认。复核结果会写回结论并进入审计记录，形成人机协作闭环。” |
| 72–82s | 打开「示例企业G」 | “数据缺失的企业不会被静默判为正常——结论直接标‘待核实’。” |
| 82–90s | 打开「示例企业H」 | “模型不可用时，系统降级为本地规则并显式标注，而不是假装正常。产品不承诺收益、不给买卖建议。” |

## 录制检查表

- [ ] 提前启动服务，确认无 404；
- [ ] 浏览器缩放 100%，关闭无关书签/通知；
- [ ] 展示「AI 证据链」的时间不少于 20 秒（这是核心差异点）；
- [ ] 必须出现“数据缺失→待核实”和“模型降级”两个反例；
- [ ] 结尾出现合规声明画面（不构成投资建议）。

## 备用一镜到底（60 秒精简版）

首页 → 开始排查 → 企业A 证据链 → 修改复核 → 企业G 待核实 → 结尾声明。
